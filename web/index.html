Un radar semanal para explorar perfiles con ADN Boca.

Cada semana, FotMob destaca jugadores de varias ligas. Este radar reúne el perfil de temporada de esos candidatos y los ordena con un modelo que aprendió de ejemplos definidos manualmente como perfiles con ADN Boca. El resultado es una primera lista de nombres para explorar, no una recomendación automática de fichaje.

La lista cambia semana a semana. Una liga aporta candidatos cuando FotMob ya publicó su equipo de la fecha y hay datos suficientes para identificar y puntuar a los jugadores. La planilla muestra hasta cinco; el corte por puesto ofrece otra mirada sobre esos perfiles.

Candidatos por puesto

El borrador del tweet se arma aparte de la planilla: selecciona hasta tres candidatos por grupo y los ordena con el puntaje del modelo. Puede haber menos de nueve si algún grupo tiene menos candidatos disponibles. Acá ves el corte por puesto y, cuando hay datos guardados, hasta tres puntajes de la señal de menciones. El sistema prepara el borrador; la publicación queda fuera de esta etapa.

El pulso de las menciones

Además de los datos de cancha, el radar recoge comentarios de YouTube y textos de prensa para estimar el tono de las menciones. Es una señal exploratoria, no una encuesta de toda la hinchada. Cada medición refleja cuándo se consultó la fuente, no la semana del equipo de la fecha; esta página solo muestra los datos guardados.

Hasta 5 del consolidado. La tabla muestra el puntaje medio; el orden prioriza el máximo registrado y luego la media.

Cómo está hecho

De los destacados al radar

  1. Un punto de partida semanal: usamos los equipos de la fecha de FotMob que ya están publicados para la semana cerrada.
  2. Una ficha más completa: reunimos goles y asistencias de todos los torneos de club de la temporada, no solo de la liga.
  3. Una comparación consistente: el modelo guardado ordena los perfiles con las etiquetas manuales del proyecto; la corrida semanal no vuelve a entrenarlo.
  4. Una lista para explorar: mostramos hasta los cinco primeros del modelo y dejamos aparte los casos que no se pudieron identificar o puntuar.
  5. Una señal de menciones: combina YouTube (40%) y prensa (60%) cuando ambas fuentes están disponibles. Son pesos provisionales; si solo hay una fuente, se usa esa al 100%.

Qué mira el modelo

Para comparar perfiles, combina goles, asistencias, edad y posición. Se entrenó con ejemplos que el proyecto etiquetó manualmente como ADN Boca; aprende de ellos en vez de aplicar una regla fija por goles o rating.

    No usamos el rating: esa calificación no está disponible de forma comparable para todos los candidatos. Como las etiquetas están desbalanceadas, el entrenamiento equilibra el peso de cada grupo.

    Cómo comprobamos el modelo

    Separamos los datos por jugador para que una misma persona no aparezca tanto en el entrenamiento como en la prueba. Además, reservamos las temporadas desde 2023 para comprobar cómo funciona con jugadores más recientes.
