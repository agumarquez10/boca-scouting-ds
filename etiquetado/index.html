Etiquetado de sentimiento

Etiquetá cada texto según lo que expresa sobre el jugador: −1 negativo, 0 neutral o mixto, +1 positivo. Si no se entiende o no habla del jugador, usá "no se entiende". Las etiquetas se guardan en este navegador; al terminar descargá el CSV y guardalo como data/etiquetado/etiquetas.csv. La herramienta no muestra el puntaje del motor, a propósito.
